### 🎉 Hello, I'm DevTri Campus! 👋

**A Full-Featured School Management Mobile App** built with ❤️ in Flutter + Firebase

- ✨ Beautiful, responsive UI for both **Admin** and **Student** roles
- 🔥 Real-time sync with Firestore
- 🎓 Student management, fee tracking, notices, educational videos & more

---

### ✨ Features

#### 🔐 Authentication
- Secure login with Firebase Auth
- Role-based access (Admin / Student)
- Beautiful loading & splash screens

#### 👨‍💼 Admin Dashboard
- Add / Edit / Delete Students
- Create & broadcast Notices
- Upload & manage Educational Videos
- Fee collection & tracking
- Overview analytics dashboard

#### 👩‍🎓 Student Dashboard
- Personalized home feed
- View invoices & payment history
- Real-time notifications
- Watch educational videos


### 🛠 Technologies Used

Flutter • Dart • Firebase (Auth + Firestore + Storage)
Provider / Riverpod • Local Notifications • MVVM Architecture

📁 Project Structure
textlib/
├── config/              → Firebase config & constants
├── features/
│   ├── auth/            → Login, role selection
│   ├── admin/           → All admin screens
│   ├── dashboard/       → Student & admin dashboards
│   └── splash/          → Splash screen
├── services/            → Firebase services (auth, notice, video, fee)
├── theme/               → Dark/Purple theme + colors
├── widgets/             → Reusable components
└── global/              → Static data (videos, etc.)

🚀 Installation
Bash# 1. Clone the repo
git clone https://github.com/furqan-dev01/dts-scholar.git
cd dts-scholar

# 2. Get dependencies
flutter pub get

# 3. Add Firebase config
# → Download google-services.json → android/app/
# → Download GoogleService-Info.plist → ios/Runner/

# 4. Run it!
flutter run

🎯 Usage
Admin → Login with admin credentials
Student → Login with student roll number / email
